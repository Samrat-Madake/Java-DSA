If your goal is **DSA interview preparation**, recursion should be learned in layers. Don't jump directly to hard backtracking questions.

# Phase 1: Recursion Fundamentals

Learn:

* Base case
* Recursive case
* Call stack
* Stack overflow
* Recursion tree
* Tail vs non-tail recursion

### Questions

1. Print numbers from 1 to N
2. Print numbers from N to 1
3. Sum of first N natural numbers
4. Factorial of N
5. Power(x, n)
6. Fibonacci Number
7. Count digits in a number
8. Sum of digits
9. Reverse a number
10. Check palindrome number

---

# Phase 2: Recursion on Arrays

Learn:

* Processing one element at a time
* Shrinking problem size

### Questions

1.occurrence Find maximum element
2. Find minimum element
3. Sum of array elements
4. Linear search
5. Find all occurrences of a target
6. Check if array is sorted
7. Reverse array recursively
8. Binary search recursively+

---

# Phase 3: Recursion on Strings

Learn:

* String slicing
* Index-based recursion

### Questions

1. Reverse string
2. Check palindrome string
3. Remove all occurrences of a character
4. Replace character recursively
5. Count vowels
6. Remove duplicate characters
7. Convert string to integer (atoi)
8. Generate all substrings
9. Check anagram recursively
10. String compression

## Must-Do Questions Before Moving to DP

1. Factorial
2. Power(x,n)
3. Fibonacci
4. Check Sorted Array
5. Binary Search
6. Print Subsequences
7. Generate Subsets
8. Permutations
9. Combination Sum
10. Generate Parentheses
11. N-Queens
12. Sudoku Solver
13. Tower of Hanoi
14. Josephus Problem
15. Climbing Stairs

Master these 15 questions and you'll understand about **80% of recursion patterns** used in interviews and competitive programming.
